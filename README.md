# Greenden - Responsive Website Clone

A fully responsive replica website inspired by Greenden, built using HTML, CSS, and Tailwind CSS. The project focuses on responsive layouts, modern UI design, and mobile-friendly user experience.

## 🚀 Features

* Responsive design for all screen sizes
* Modern UI inspired by Greenden
* Navigation bar with multiple pages
* Product section
* Contact page
* Mobile responsive layout using media queries / Tailwind CSS
* Clean and structured code

## 🛠️ Technologies Used

* HTML5
* CSS3
* Tailwind CSS
* Flexbox
* Media Queries
